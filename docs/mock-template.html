v1.22 · FASTA / FASTQ toolkit

Inspect, filter and reshape sequence files from the command line.

SeqFu is a fast, general-purpose toolkit for FASTA and FASTQ files. Core programs run as seqfu <command>; companion tools ship as standalone fu-* utilities.
